## 🐶 关于 Heartyu

<div align="center">

<img src="Heartyu surface.png" width="400" alt="Heartyu preview">

</div>

**Heartyu（하튜）** 是一只住在桌面上的金毛寻回犬。

它的名字来自 **Heart** 和它最喜欢挂在句尾的 **tyu**。听起来像一句轻轻的 “heart you”。

Heartyu 有着明亮而温暖的性格。它爱笑、爱撒娇、擅长跳舞，也总想带着望远镜去进行下一段冒险。

作为一名小小的心灵管理者，它很擅长发现大家的情绪。当你辛苦时，只要摸摸它，它会认真地告诉你：“今天也辛苦了tyu”～

它珍惜每一段快乐和冒险的回忆，最想守护的人是 **ATINY**。只要举起会发出白色光芒的 Lightiny，它就会立刻打起精神，认真地为 ATINY 应援。

希望梯尼在工作、学习的时候，这只小小的 Heartyu 会一直陪着你 ♡
